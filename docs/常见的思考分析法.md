将业界成熟的分析 思考 归纳 判断的思考分析工作法生成skills 写入数据库中，方便后续Agent 构建时使用，
战略规划类包含：
1. SWOT：核心：从 Strengths（优势）、Weaknesses（劣势）、Opportunities（机会）、Threats（威胁）四个维度综合分析内外部环境。应用：常用于项目启动前的可行性分析，或企业战略制定。
2. PEST / PESTLE 分析：核心：宏观环境分析工具。包括 Political（政治）、Economic（经济）、Social（社会）、Technological（技术），扩展版加上 Legal（法律）和 Environmental（环境）。应用：在梳理项目背景时，用于识别不可控的外部宏观因素。
3. OGSM 模型：核心：将战略落地的工具。包含 Objective（长期目标）、Goals（短期具体目标）、Strategies（策略）、Measures（衡量标准）。应用：比SMART原则更进阶，它将“做什么”与“怎么做”以及“如何衡量”进行了强关联。
4. 安索夫矩阵：核心：营销和增长战略工具。通过“现有产品/新产品”与“现有市场/新市场”的组合，得出四种增长策略：市场渗透、市场开发、产品开发、多元化。应用：项目梳理时用于明确业务拓展方向。

问题分析与解决类包含：
1. MECE 原则：核心：Mutually Exclusive, Collectively Exhaustive（相互独立，完全穷尽）。由麦肯锡提出，确保在拆解问题时没有重叠、没有遗漏。应用：这是金字塔原理的底层逻辑，也是所有逻辑梳理的基础。
2. 5W2H 分析法：核心：Why（为何）、What（何事）、Where（何地）、When（何时）、Who（何人）、How（如何）、How much（多少成本/量化）。应用：项目任务梳理、需求澄清。能够快速覆盖项目的完整维度，防止遗漏关键细节。
3. PDCA 循环：核心：Plan（计划）、Do（执行）、Check（检查）、Act（处理/改进）。应用：质量管理和流程优化。强调闭环思维，通过持续迭代来提升项目质量。
4. 鱼骨图：核心：又名因果图。将问题的结果（鱼头）与造成问题的各种可能原因（鱼骨）进行结构化分解。应用：项目复盘时用于根因分析，或解决复杂的技术难题。
5. KT 法：核心：Kepner-Tregoe 法，包括情景分析、问题分析、决策分析、潜在问题分析四个理性步骤。应用：适用于高风险项目的重大决策，避免因感性判断导致失误。

项目管理与执行类：
1. WBS：核心：Work Breakdown Structure（工作分解结构）。将复杂的项目目标，按照层级分解为更小、更易管理的工作包。应用：项目启动阶段的核心工作，是估算工期、成本和资源的基础。
2. 甘特图：核心：以条形图展示项目任务的时间线、起止日期、依赖关系和负责人。应用：进度跟踪和资源协调。
3. 关键路径法：核心：识别项目中决定最短工期的任务序列。如果这些任务延迟，整个项目就会延迟。应用：在时间紧张的项目中，用于识别哪些任务绝对不能延期，以及哪里可以压缩工期。
4. RACI 矩阵：核心：责任分配矩阵。明确每项任务的 Responsible（执行者）、Accountable（负责人）、Consulted（被咨询者）、Informed（被告知者）。应用：解决跨部门、多角色项目中的权责不清问题。

逻辑与沟通类
1. SCQA 架构：核心：Situation（背景）、Complication（冲突）、Question（问题）、Answer（答案）。麦肯锡咨询顾问常用的叙事结构。应用：撰写汇报PPT、项目立项申请或商业计划书。它能确保开场就抓住听众注意力，并建立逻辑认同。
2. 电梯演讲：核心：在极短时间（通常30秒-1分钟）内，清晰阐述项目的核心价值、目标受众和独特优势。应用：用于向高层快速汇报项目亮点，或争取跨部门资源。
